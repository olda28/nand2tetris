# nand2tetris
Implementing nand2tetris, step by step, chapter by chapter - but optimally.
I try to use the most effective solution by combining math and improvisation.

You can find the original project at [https://www.nand2tetris.org](https://www.nand2tetris.org).
This project includes solution but also contains individual steps - if you're stuck, feel free to look without immediate solution spoilers.
