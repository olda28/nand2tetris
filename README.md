# Nand2Tetris: Bit by bit
See the live version at: [https://olda28.gitbook.io](https://olda28.gitbook.io)

Implementing nand2tetris, step by step, chapter by chapter - but optimally.
I try to use the most effective solution by combining math and improvisation.

This project includes solutions but also contains individual steps with hints, detailed explanations - if you're stuck, feel free to explore without risking spoiling the thrill of finding the solutions yourself.

# Diagrams
All of the diagrams found in the GitBook can be found in the "diagrams" directory. They are in XML format - to load them open [Falstad's circuit editor](https://falstad.com/circuit/circuitjs.html), click "File" in the top right corner, "Open File..." and select the corresponding XML file to load the diagram.
