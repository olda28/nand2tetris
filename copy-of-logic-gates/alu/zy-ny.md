# zy, ny

## Definition

```
// if (zy == 1) sets y = 0        // 16-bit constant
// if (ny == 1) sets y = !y       // bitwise not
```



## Solution

This is exactly equivalent to the `zx` and `nx` instructions, except applied to `y` instead of `x` .
